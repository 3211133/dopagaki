# X Fullscreen Video Playlist

X（旧 Twitter）のタイムラインやリストに並んでいる動画を、順番に連続再生する Chrome 拡張です。
動画が終わると、自動で次の動画に移ります。

> 非公式の拡張です。X Corp. とは関係ありません。

## 機能

- 「▶ 連続再生」ボタンで、画面に近い動画から順に連続再生
- 動画が終わると次の動画へ自動で移動（足りなければ自動でスクロールして読み込み）
- 広告ツイートの動画は自動でスキップ
- 3つの表示モード（右下の「表示: …」ボタンで切り替え。選択は保存されます）

| モード | 動作 |
|---|---|
| 画面全体 | ブラウザごと全画面にして再生 |
| ブラウザ内 | 全画面にはせず、ブラウザの表示領域いっぱいに表示 |
| その場 | タイムライン上の動画を画面中央に出して、その場で再生 |

## 対象

- Chrome / Edge など Chromium 系ブラウザ（Manifest V3）
- `https://x.com/*`、`https://twitter.com/*`
- ホームのタイムライン、リスト（`/i/lists/...`）で動作確認済み

## インストール

1. このリポジトリをダウンロード（またはクローン）します。
2. Chrome で `chrome://extensions` を開き、「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」で、このフォルダを選びます。
4. x.com を開き直します。

コードを更新したときは、`chrome://extensions` で拡張を更新（リロード）し、x.com を再読み込みしてください。

## 操作

| 操作 | 動作 |
|---|---|
| 右下の「▶ 連続再生」 | 開始 |
| 右下の「■ 停止」 | 終了 |
| `→` / `n` | 次の動画 |
| `←` / `p` | 前の動画 |
| `Esc` | 終了（「ブラウザ内」「その場」モード）。「画面全体」では全画面を抜けると終了 |

## 仕組み

X は画面に入った動画しか読み込まないため、再生前にその場で動画を読み込ませてから表示します。
「画面全体」「ブラウザ内」では、動画要素を専用の黒い枠に一時的に移し、切り替え時に元の位置へ戻します。

## 注意

- X のページ構造（DOM）に依存しています。X 側の変更で動かなくなることがあります。
- 広告の判定は、ツイートに「広告」「Ad」「Promoted」「プロモーション」のラベルがあるかどうかで行っています。
- 外部への通信やデータ収集は行いません。表示モードの設定だけを、ブラウザの `localStorage` に保存します。
